# Projeto de Análise de Dados - COVID-19

## Sobre o projeto

Este projeto apresenta uma análise exploratória dos dados da COVID-19 no Brasil.

O objetivo é analisar a evolução dos casos e óbitos e identificar os estados com maior número de casos e óbitos acumulados no período analisado.

## Período analisado

- Início: 01/01/2022
- Final: 30/06/2022
- Registros: 1.017.039
- Colunas: 17

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Spyder

## Etapas da análise

1. Importação dos dados
2. Análise exploratória
3. Verificação de valores nulos
4. Tratamento da coluna de data
5. Análise de casos acumulados por estado
6. Análise de óbitos acumulados por estado
7. Análise da evolução dos novos casos
8. Análise da evolução dos novos óbitos
9. Análise da relação entre população e casos acumulados

## Principais resultados

São Paulo apresentou o maior número de casos acumulados entre os estados analisados, com 5.718.492 casos.

Também foi realizada a análise dos estados com maior número de óbitos acumulados e da evolução dos casos e óbitos ao longo do período.

## Visualizações

O projeto contém cinco gráficos principais:

- Top 10 estados com maior número de casos acumulados
- Top 10 estados com maior número de óbitos acumulados
- Evolução dos novos casos de COVID-19
- Evolução dos novos óbitos por COVID-19
- Relação entre população e casos acumulados

## Conclusão

A análise demonstra como ferramentas de análise de dados podem ser utilizadas para explorar informações epidemiológicas, identificar padrões e comparar diferentes estados brasileiros.

O projeto foi desenvolvido utilizando Python, Pandas e Matplotlib.
